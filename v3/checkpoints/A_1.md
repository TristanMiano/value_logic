## 3. Provisional representation: versioned finite constraints and loss queries

Select a **versioned finite rational constraint-and-loss interface** as the
provisional starting representation. Probability or credal coordinates are an
explicit adapter for records whose meaning is linear expectation. The outer
interface does not assert that arbitrary usefulness numbers are probabilities.

For the first bounded investigation, prefer **known calibrated rational payoff
rows and interval/set-valued uncertainty**; do not require an unsupported point
probability. The smallest supported expectation instance is a supplied finite
normalized source with known rational payoff rows and a declared target service.
Unknown scale/offset remain explicit optional mathematical adapters, rather
than hidden freedoms in that starting instance. The inherited native
source/term system covers a broader rational piecewise-affine fragment under
its original assumptions; the smaller certificate companion does not thereby
implement that whole language.

### 3.1 Required fields and ownership

| Component | Required content and permitted meaning |
|---|---|
| Scope | Theory, interpretation, program, checker, source, objective, method and resource-model versions, using the P3-01 record contract. |
| Source | Finite coordinates and represented constraints; origin, accessibility, construction cost and any nonemptiness/containment evidence. A normalized-law adapter names `p >= 0`, `1^T p = 1` and its admitted restrictions explicitly. |
| Losses | Known rational rows or admitted native terms, their semantic payoffs, units and applicability premises. Rational coefficients can change between requests; jointly uncertain products require another justified route. |
| Observation | Whether data are exact subjective expectations, realized observations or learned estimates; available noise/coverage bounds; scale and offset sharing; receipt event and provenance. |
| Retained information | Raw rows, a task-specific summary, constraints or a source-preserving profile, with its decoder, dependency references and actual retrieval permissions. An identifier alone is not access to discarded data. |
| Consumer service | Full law, specified expected losses, interval, preference relation or some optimal action; decision criterion and tie/commitment requirements where applicable. |
| Evidence and status | Arithmetic certificates, externally checked input binding and semantic premises are separate. Pending, no result, conflict, failure and stale scope cannot be silently converted to false or to a valid numeric warrant. |
| Resource account | Construction, acquisition, arithmetic precision, retention, lookup, decoding, proof search, checking and decision costs on the admitted access model. Costs may be unknown until measured; they are not zero by omission. |

This is a representation contract, not a new implemented record manager or
update algorithm. The existing executable claim is the narrower mathematical
companion and native cases described below. The schema makes their input and
output obligations visible to the future bounded producer.

Here “finite rational” describes the encoded coefficients and constraints;
unknown source coordinates may range over real intervals. The interface does
not supply an exact-real measurement oracle. A later producer of a rational
forecast, interval or approximation must declare its numerical precision and
error/coverage meaning. Conditional certificate validity over a source remains
different from showing that the source covers the intended application.

### 3.2 A present usable instance

The calibrated starting core already has a simple instance: on a supplied
three-case simplex, the known loss row `(0,1,0)` has expectation `p_2`.
An exact value therefore answers that coordinate query without identifying the
remaining law; if no such value is supplied, the source retains its compatible
set and the interval `[0,1]`. This is the inherited linear-expectation case in
P3-02 §§2–3, with no guessed weights or new execution. P3-01's
[EX01](../foundations/01_separating_examples.md#ex01--unresolved-truth-failed-search-and-finite-coherence)
also supplies finite assessment cases for received Boolean constraints without
claiming that they are complete arithmetic models.

The saved P3-02 standalone example supplies three states, old loss row
`L = [[0,1,0]]`, target `C = [[1,0,0]]`, and an unknown common positive scale
and offset. Its [original input](../work_logs/P3_02_2026-10-07_S1/development/constructive_cli_2_files/input.json)
is bound to a [saved certificate](../work_logs/P3_02_2026-10-07_S1/development/constructive_cli_2_files/certificate.json)
and an [executed interface record](../work_logs/P3_02_2026-10-07_S1/development/constructive_cli_2.json).

The existing companion certifies that the old target is not globally
recoverable. Two extra rows, `(1,2,1)` and `(1,1,0)`, are sufficient and minimal
under freely chosen rational queries. With the old raw value `v_0` and new
values `v_1,v_2`, the declared observation model gives

```math
p_1=\frac{v_2-v_0}{v_1-v_0},\qquad v_1-v_0=s>0.
```

The retained example has two different laws and offsets giving the same raw
record and the same requested `p_1=1/2`. It demonstrates target recovery without
full-law or offset recovery. The saved run separately checks original input
binding, exact arithmetic and preservation of an existing output. Reusing it
at this gate adds no execution count or historical time.

This example is a usable finite mathematical interface even though it does
not produce a subjective law from unresolved arithmetic. It accepts a declared
measurement design; it does not take empirical samples, choose a learning rule,
prove the payoff interpretation, or implement a budgeted acquisition policy.
The symbolic ratio is an external arithmetic decoder, not an automatically
available native variable-division rule. Native eligibility has its separate
P3-02 §13 evidence and directed-unit premises.

### 3.3 Why this is a reasonable provisional choice

It uses an already specified and exercised finite fragment, retains dependencies
and uncertainty when the consumer needs them, and can expose only a smaller
loss summary when P3-02's recovery criterion permits it. It also has an exact
ordinary reconstruction, which supplies a strong reference implementation and
keeps notation from being mistaken for a new learning guarantee.

The choice is for the next restricted investigation. It does not require
finite complete models of arithmetic, a global consistency decision, scalar
values everywhere, a fixed universal bound, or a neural representation.
Within each finite payoff table the numerical domain is declared; later tasks
may revise it with a new encoding, proof and resource contract.
