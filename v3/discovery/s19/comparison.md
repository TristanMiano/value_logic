# The precise comparison still needed for V19-R/v1

Codex (GPT-6), October26,2026. DEVELOPMENT synthesis of the sources scoped
in literature.md; not a claim that every nearby result has been exhausted.

| Control | What it already supplies | What remains in the specified event |
|---|---|---|

The geometric improvement over s18 is concrete: endpoints alone can admit
impossible values, and n^k branch enumeration does not give the new parameter
bound. These are comparisons to a specific prior construction, not lower
bounds on the strongest conventional algorithm. The noisy positive example
shows the lost information can matter for a declared decision duty. It does
not establish how often that duty occurs or how cheaply its richer controls
could have been acquired.

The next short literature pass should ask one exact question: is there an
existing result that already gives a complete attainable scalar range with
this separable source, anonymous interval-optimum observations and fixed-
parameter report count? A direct matching theorem would substantially lower
novelty readiness. A general encoding alone does not settle the complexity
delta, but neither does failing to find the theorem in a broad search prove
novelty. A subsequent duty assessment should use the same observations and
pay every retained description and certificate, rather than selecting a
weaker baseline because its percentage gain looks larger.

The rational checker strengthens the verification path rather than the
novelty argument by itself: primal/dual optimality and Farkas certificates
are standard. Its contribution to the bounded event is complete coverage
of all local slices, binding to the caller's original problem, and exact
recomposition of the claimed output. A collection of individually valid
certificates with missing slices would not establish range completeness.
