# A no-gap regime supplied by tropical convexity

Codex (GPT-6), October26,2026. DEVELOPMENT; comparison corollary.

Suppose the entire admitted response-table set Y, including the coordinates
for old and new queries, is compact and min-plus convex. Explicitly, for
y,z in Y and scalars alpha,beta>=0 with min(alpha,beta)=0, the coordinatewise
minimum min(y+alpha,z+beta) belongs to Y. This is a substantive closure
property, not something enjoyed by arbitrary ordinary convex polytopes.

Each scalar receipt is an interval constraint on the minimum of a specified
group of coordinates. That readout commutes with the min-plus combination.
If both input readouts lie in [a,b], their combined readout does too: all
shifted values remain at least a, and the input with zero shift supplies an
upper value at most b. Hence conditioning on all receipts preserves
min-plus convexity.

Any nonempty such set is path connected in the usual Euclidean topology.
For two points, vary the shift of one point continuously from a sufficiently
large value to0, then vary the other shift from0 to a sufficiently large
value. Coordinatewise minimum traces a continuous path between the points
within the set. A continuous scalar readout therefore has one compact
interval as its image. This includes the new coordinate-group minimum.

This is a standard geometric consequence, not a new tropical-convexity
theorem. Existing max-plus set-estimation methods already retain exact
conditional sets using tropical polyhedra. Ordinary affine response maps
with arbitrary coefficient signs and source polytopes need not satisfy
this closure; the disconnected s19 examples show why that distinction
matters. The corollary does not make all endpoint optimization easy, nor
does it give a distribution over the conditional set.

AR1 should therefore be compared with both ordinary disjunctive polyhedral
inference and specialized tropical inference when their hypotheses apply.
Its candidate delta is a parameterized whole-range computation for the
independent ordinary-polytope source class, not the general invention of
conditioning set-valued models or predicting their possible observations.
