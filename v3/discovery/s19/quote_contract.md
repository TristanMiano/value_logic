# A fair duty for retaining scalar optimization quotes

Codex (GPT-6), October 26, 2026. DEVELOPMENT; application contract and controls.
This motivates the conditional-receipt algorithm without claiming a measured
service saving or privacy theorem.

## What the reasoner actually receives

A service has a fixed collection of configurations with unknown response
vectors x_i. The client has warranted configuration-specific regions B_i,
and may submit a linear weighting or other declared affine response rule.
The service returns the minimum response value. Historical records retain
the request, scope/version, error allowance and value, but may not contain
the winning configuration or its whole vector. Changing the weighting is a
counterfactual query about these same vectors, not an independent new draw.

Examples of such an interface include value-oracle fitting and a record of
cost quotations. These are proposed duties, not collected deployments. The
conditional source is useful only if the B_i and observation error envelopes
are warranted. Independent uncertainty means the admitted set is a product;
it need not be a claim of probabilistic independence. Real correlations may
make that product conservative, or an erroneous B_i may invalidate it.

The client pays for and retains the original source descriptions, k objective
specifications, k value/error records and any relevant version evidence.
Calling this a k-scalar memory cost while omitting those descriptions would
be misleading. Access to a discarded vector requires a priced recovery path.

## A concrete model-criticism consequence

In the two-segment example, the old coordinate-minimum receipts are both0.
The full possible new sum-objective values are {1,2}; the smallest interval
containing them is [1,2]. A new reported value3/2 is therefore inconsistent
with the common fixed-source model despite satisfying its interval bounds.
This is a useful check of a fallible model without identifying the vectors.
It does not say which old report, new report, source bound or invariance
assumption failed. Revision needs separate evidence about those alternatives.

With old observation tolerance epsilon=1/10, the exact predictive set is
[1,21/20] union [19/10,2]. A new report interval disjoint from that set can
still refute joint consistency. A statistical interpretation needs a common
coverage guarantee for all intervals; the deterministic computation supplies
no extra confidence probability. Interval endpoints alone cannot detect this
particular contradiction.

The same set supports a declared downstream loss g(V), evaluated over its
components. Nonmonotone losses or exclusion bands can use gaps. For monotone
g, one sharp endpoint already suffices, so full-set computation is unnecessary.
A direct feasibility query for one proposed new value or band is another
strong control; it may be preferable to materializing the entire range.
A recovered source point is a possibility witness, not a deployable action
known to be optimal in the actual unknown source.

## Strong comparison contracts

1. **The same scalar observations:** ordinary max-affine mixed-integer
   fitting, disjunctive LP and the identical subset algorithm recover the
   same source and answers. The proposed delta is a structured exact
   algorithm and resource bound, not exclusive access to this information.
2. **Winner labels retained:** each observation supplies its attaining
   generator index. The assignment is fixed; the compatible source is one
   product of convex slices. A new scalar minimum has one interval image,
   obtainable with local LP extrema and no subset-cover search. Labels cost
   at most k*ceil(log2(n)) bits plus their provenance. This inexpensive
   metadata can be much more valuable than dropping it and reconstructing
   ambiguity later. No claim is made that scalar-only storage is best.
3. **Whole winning vectors retained:** their known coordinates add stronger
   constraints and support direct re-evaluation. Ordinary persistent
   optimization and primal/dual reuse must receive that benefit. Their
   acquisition/storage costs and permitted disclosures differ from the
   scalar-only duty; they cannot be silently withheld to favor the candidate.
4. **The full original source remains available:** directly optimize it or
   use its established solver. The inverse problem has no intrinsic priority.

Thus the theorem can be a useful moderately novel inference result even if
an ordinary implementation ties. Its value depends on a real scalar-only
information contract or a justified retention tradeoff. A larger exact range
artifact, an imposed weak comparator, or an application story alone does
not establish either novelty or economic superiority.
