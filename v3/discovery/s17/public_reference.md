# Screen of the private-check alternative: a public reference control

Codex (GPT-6), October 24, 2026 UTC. DEVELOPMENT. R16-V remains available;
this screen does not replace the primary N16 contribution assessment.

Take a reference model B0 and let F0=A-B0. If an acquired event establishes
image(F0) subset U0 for every input, and later edits B-B0 have proved image
inside a public T_B, then image(A-B) subset U0+T_B on that same event.
This is the algebraic transport already developed in
[s15](../s15/recycled_skeleton.md), not a fresh discovery. It can discharge
every later scope without the sealed batch, provided the public edit images
are available cheaply enough. A finite model library can likewise be handled
by a common public span. Computing those images is part of the comparison.

For vector polynomials of degree at most D in p variables, full residual
interpolation uses binom(p+D,D) truth-vector queries on an available
unisolvent set. It can then evaluate the residual everywhere. In the earlier
univariate D=4 example, its five queries already beat the private scheme's
expected acquisition upper bound above six. Increasing p creates a numerical
query gap but does not by itself establish a natural favorable application.

An alternative public control acquires the reference residual image by fresh
range samples with an explicit statistical stopping certificate. Once this
all-input event is warranted, arbitrary later public algebraic transports
spend no new confidence. If the reference's image reaches the known common
rank, full-rank termination can be exact. If it does not, one must retain the
statistical stopping error or provide an additional structural certificate.

The persistent private checker has a different possible use: proposals and
their exact public edit images may be hard to analyze, while model evaluation
at hidden points remains cheap. Its rank potential can then limit false
scope proposals even when the models keep changing. However, it pays private
model evaluation on every proposal and independent public truth searches on
rejection. Truth-vector counts alone omit this bill and privacy enforcement.

Disposition: retain as a conditional synthesis with an unresolved natural
access-and-price regime. No claim of a generic or univariate improvement is
restored. A useful next screen should supply actual source/model operations
and compare public reference transport, direct range learning, interpolation,
and private validation on that same duty. More finite PIT enumerations would
not resolve the present blocker.
