# Partial range service: prospective development check

Codex (GPT-6), October29,2026 UTC. Separate from completed P3-11-A1.
Freeze this plan, proof, implementation, runner and exact dependency bytes
before first execution. Every attempt gets a fresh directory. Preserve failures.

The question is whether incomplete rational evidence safely brackets the
complete attained image and sometimes answers a query without complete local
optimization. Six already exposed audit cases have explicit coordinate boxes:
no_receipts, noisy_envelope, degenerate_segment, huge_constant,
inconsistent_constant, maximal_cover_loss. Their existing complete certificates
are controls, not new or hidden confirmation. No optimizer is needed in this
panel. The transformed cases lacking explicit coordinate bounds are outside
this prototype's input contract, not silently discarded successes.

For each case, start unknown; perform two box-propagation sweeps for each mask
in block/mask order; then ingest existing complete certificates in that same
fixed order. At every update check local and global inner/exact/outer inclusion,
monotonicity, empty/unknown distinction and exact rational source reconstruction.
Probe each true component endpoint/midpoint, each gap midpoint, exterior points,
adjacent bands and a 400-digit enclosing band. Query selection uses the exposed
control to cover these cases; this is not an adaptive-oracle performance study.
At the end the global bracket must equal the complete certificate range.

Two hand-computable three-receipt cases separately check interleaved row indexing,
nonminimal dual support, propagation only to supersets, and point coverage only
to subsets. A strict Farkas proof uses just two of three selected upper rows.
Check invalid digest, negative/bool indices, missing dimensions, infeasible
points, negative multipliers, wrong dual identities, non-strict contradictions,
malformed certificate fields, false endpoints and late invalid duals. Rejection
must preserve the entire evidence state. Caller input/output mutation must not
modify it. Query validation and unsupported-box input rejection are included.

Specifically record the noisy-envelope query [-5/4,-6/5] before and after box
propagation, before any complete certificate is delivered. Whether it resolves
is an outcome, not an assumption. Also record the number of supplied full face
certificates needed for global equality under the predeclared order. Retained
control certificates were produced earlier; a delivered certificate is not a
new LP call and no runtime or fee saving is inferred from this count. Report
all compilation, propagation and point/certificate storage costs explicitly
enough to prevent a false free-reuse claim. The ordinary same-code method ties.

This finite panel does not certify arbitrary input correctness, mathematical
novelty, numeric-producer completeness or an empirical deployment gain. The
theorem in partial_ranges.md supplies the general conditional argument.
