# Reproduce s13 without replacing scientific evidence

Codex (GPT-6). Same-model DEVELOPMENT, Python3.12.14 on Windows11. The probes
use the standard library; [environment](environment.json) records the actual
interpreter and base commit. The host's instability allowance was available,
but no scientific execution required a retry. A REFUTED candidate is a normal
scientific outcome, not a failed process.

Inspect each source before replay. Many scripts write JSON beside themselves
and import earlier local probes or repository code. Copy source bytes and
declared dependencies to a short isolated replay directory, preserving names;
write new stdout/stderr there. Never rerun into s13 or overwrite saved results.
The final gap_probe.py and sharp_probe.py print JSON to stdout. Their first
stdout is also retained as JSON. Existing output self-hashes and dependency
hashes bind executed sources; [manifest](manifest.json) binds the closing notes,
clock and output set. These identities do not constitute independent review.

Probe scopes include Boolean/ordered permissions, receipt/model envelopes,
near-optimal and price-ray warrants, tolerance calibration, inspection/write
budgets, invoice edge/rate/channel bounds, restricted-source oracles, tariff
ambiguity and positive spectral response certificates. Every JSON retains its
finite domain. bias_potential.json preserves a rejected inequality. The
n2/cap3 biased-oracle row has the explicit scope correction in biased_invoice.md.
No full integrated service, native speed benchmark or F01 panel was executed.

Administrative reconstruction and integrity checks, from the checkout root:

```text
python v3/discovery/s13/reconcile.py
python v3/discovery/s13/verify_evidence.py
python -m verification
python v3/checks/math_markdown.py
python tools/check_repo_paths.py
python tools/evidence_paths.py verify
```

Stage intended changes before the index-based path check. Reconciliation is
idempotent and appends missing replacement-ledger rows once. close_records.py
is a guarded one-time reporting mutation, not a replay command. Do not run
start.py, mark.py or clock_source.py init/serve to reconstruct historical time.

[Publication](publication.md) records actual check results and remote status.
Repository checks test integrity and existing finite software properties; they
do not independently establish the new mathematical claims or promote them.
