# Smaller target, but no additional physical gain on the exposed policy pair

**DEVELOPMENT — Codex (GPT-6), October 14, 2026 UTC.**

cq01 evaluates both loggers on all 64 six-node indicator worlds: 128
world/logger cases. The direct contrast planner and ordinary receipt-reusing
alternative-policy replay each require a total of 156 additional fee units;
auditing every still-hidden coordinate requires 1,092. There are 106 cases
with no additional contrast audit. The exact target planner has only nine
nontrivial/terminal residual states in total. Its target is smaller than
full hidden-row identification, but ordinary replay already captures all
observed physical benefit in this pair.

cq02 evaluates both loggers on all 1,024 ten-node worlds: 2,048 cases. Direct
minimax target evaluation totals 1,852 additional fee units, versus 1,788
for ordinary replay and 22,484 for full hidden-row identification. The
target planner costs more on eight worlds and is never cheaper in this
screen. This is compatible with its **worst-case** objective; minimax
optimality does not imply lower realized or source-average cost on every
world. It has 19 residual planning states and 1,596 zero-query cases.
All contrast values and physical additional-fee bounds check; underquoted
Bellman tables reject. These are enumerated conditional comparisons with
zero newly acquired physical observations, not 2,176 new service outputs.

Do not spend a paid learning experiment merely to repeat this unpromising
target-query comparison. Retain the checked quotation capability and the
negative matched result. The simpler ordinary syntax-pruned learner ib02
already executed 9,216 outputs with a separate reconstruction. Pruning is
not uniformly beneficial at finite horizons: the n=10 realized fees increase
on all three exposed streams, and n=16 receives no pruning while its named
preparation bill increases by 48,297 units. At n=6 the named bill decreases
slightly, with mixed realized-fee changes. Exact redundancy removal changes
the index's implicit allocation over equivalence classes; it is not a
universal finite-sample performance theorem.

The absence of target-query savings in cq01/cq02 is not a general impossibility.
For a three-node path with fees (1,2,2), let logger A query node 2 and then
node 1 on their extreme branches, and leave node 0 hidden. Let B query node
0, then node 1 if 0 is middle, or node 2 if 0 is extreme. Under the logger's
receipts {1:E,2:E}, B's from-scratch invoice is always 3: both continuations
have the same fee. A's invoice is 4. Therefore A-B=1 without a new audit,
whereas executing B's alternative action still buys node 0 for fee 1.
This case is outside the executed optimized Markov proposal pair and must
not be counted as an observed cq01/cq02 saving. An ordinary invoice-range
recurrence detects it without an expensive global diagram.

The next practical construction is consequently a **cheap direct evaluator
of the checked normalized invoice circuit**, with shared sums cancelled
before querying. Whole EVBDD minimax planning is unnecessary when local
arithmetic simplification already removes the irrelevant values. This is a
revisable development direction; no advantage over an equal-capability
ordinary direct-contrast evaluator is assumed.
