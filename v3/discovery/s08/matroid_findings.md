## Closest ordinary results and what remains

Weighted matroid rank, stochastic cover, interval worst-scenario regret,
cardinality encodings and baseline policy improvement are prior tools.
The source-specific connection supplies explicit original Boolean actions,
proof obligations and query stopping rules; it does not invent those tools.

Merino and Soto's [2019 paper](https://drops.dagstuhl.de/storage/00lipics/lipics-vol132-icalp2019/LIPIcs.ICALP.2019.83/LIPIcs.ICALP.2019.83.pdf),
sections3–4, characterizes uniformly optimal bases and nonadaptive query
sets sufficient for every revelation. Diwan et al.'s [2025 preprint for
STACS2026](https://arxiv.org/html/2512.17116v1), sections1,2.3 and4–5,
handles optimal verification certificates with closed/discrete uncertainty
areas, including a bipartite vertex-cover construction and learning-augmented
variants. That verification problem is supplied actual weights; its answer
is not a free online oracle. Its exact-optimality duty differs from our
positive-tolerance repair/replacement duty, but it is a necessary strong
ordinary comparator if this work returns to exact basis identification.

No source compiler yet recognizes arbitrary input CNF as one of these
families. The compact counter source is generated from known structure.
The public stochastic law is assumed, not learned; the earlier adequacy
counterexample still blocks inferring it from insufficient feedback. No
new complete-cost region, general induction theorem or counterfactual
model-adequacy result follows from these finite checks.

The most useful next engineering experiment is a single matched development
service using an original unstructured CNF with independent feature-cost
intervals. Its fixed incumbent can request the classical transformed q
proof through the existing complete interface. Compare actual q-proof
acquisition, interval audits, checked witness updates and replacement
against ordinary audit-first and the same induced-scenario controller.
Keep the existing finite-cohort/mode F01 source unchanged and report this
as a separate source contract. A proposed scalar query's value must include
both proof outcomes and its real invoice. This tests whether the bridge
changes purchases when source structure is not supplied by construction.

[The retained-bound transport](box_transport.md) further limits that design:
for a single original repair, the generic coefficientwise lower transport
has no guaranteed regret-bound contraction from an audit. Reweighting the
actual retained proof structure, exploiting source equalities, or buying a
new proof can be necessary. A controller must distinguish those mechanisms
from the separately improving absolute-cost/replacement bound. Multiple
logical copies with an interior feature count admit a positive guaranteed
middle-receipt contraction; that different action duty must stay explicit.
