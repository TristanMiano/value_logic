# Priced local-feedback service: developmental declaration

Codex (GPT-6), DEVELOPMENT, prepared before these service outputs. This is a
small feasibility comparison after the information/decomposition screens,
not a confirmation or a revision of F01.

Run four deterministic generated streams, 2000 requests each, with n=16 or
64 fixed-price binary queries and nonnegative threshold stopping. Include an
independent first-positive stream, correlated changing first-positive values,
a three-positive threshold and a deliberately long-prefix threshold. Seeds,
fees, audit probability 1/10 and learning-rate formulas are specified in the
saved implementation before execution. No outcome-dependent parameter tuning
is part of this panel.

Two arms use exactly the same weighted-matching learner over all disjoint
adjacent exchanges, with coupled private random seeds. One buys every missing
value on selected feedback rounds; the other buys only the certified local
prefix. Verify identical loss coefficients, actions, updates and execution
fees. This measures the information interface's benefit for the SAME exact
feedback duty. An ordinary implementation of the local interface ties it.

Also run identity, a fixed fee-based matching, and two ordinary two-arm bandit
learners over disjoint pairs with the two possible offsets. The latter buy no
additional feedback. Their policy families are smaller than all matchings;
report that distinction and retain any wins. A hindsight best fixed matching
is an unavailable diagnostic comparator, not a deployable free baseline.

Report execution fees, feedback fees and receipt counts separately. Report
matrix products, scalar updates, sampling choices and predicate/data reads in
their own categories. They do not yet have defensible common monetary prices;
do not convert their sum into a complete-cost superiority claim. These are
simulated queries with an instrumented access interface, not purchases from an
actual mathematics service. Generated ground truth used by the evaluator is
not furnished to deployment arms for free.

Keep every attempt and do not overwrite executed sources. If the local learner
loses to a no-extra-query control, narrow the claim to exact feedback/cost
reconstruction or seek a different use; do not enlarge the experiment simply
to find a favorable headline.
