# Safe-revision compact optimizer: development declaration

Codex (GPT-6), before new optimizer output. This is constructive discovery,
not held-out empirical confirmation. Preserve safe_revision.py and sr01.

Implement a separately versioned adapter with different source and target
chain relations. Compile globally projected histories, permitted flip-pair
menus, pathwise flip-count networks, source-independent private query flow,
and an epigraph of the joint original-truth/comparator-revision dynamic program.
Keep every comparator under the same certification rule; a point law supplies
no unpaid observations. Compare full querying with the optimized no-query
restriction, using the full comparator in both regret objectives.

Numerical LP output is advice. Repair query choices on a 2^20 probability
grid. Repair each terminal-mask network by propagating integer flow units
from a 2^20-unit root through feasible edges, preserving conservation exactly.
This yields a mixture of valid capped masks; independent marginal rounding
is prohibited. Check an exact worst-case upper via the chain separator and a
bounded-variable dual lower on a common 2^40 grid. Preserve raw advice,
realizations, bounds, inputs, source/dependency hashes, timings and failures.

Small cases: the exact implication example (optimum 65/64); original sr01
cases 2 and 3; a changed-target four-bit case whose source is unconstrained
and target has one implication edge; a cap-zero boundary. For each compare
the compact epigraph optimum against a full-world LP, and compare repaired
upper bounds against explicit worlds and masks. A large case uses 41 bits,
three queryable bits and cap five from sr01's declared chain, plus a target
variant at the first relation only. It checks scalability of the construction,
not population usefulness. Maximum seven cases, 45 solver seconds per arm,
with at most two unchanged retries for unexplained process failures. Retain
all attempts; repeated deterministic defects require a new version.

Potential delta: one polynomial-size randomized controller and exact regret
certificate for fixed query count, chain structure and cap, including
observation-dependent repair feasibility. No claim to generic new LP/flow/
contingent-planning machinery, paid-source economics or general causality.
