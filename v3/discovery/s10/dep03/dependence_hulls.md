# Compress the two count regions before solving their moment problem

Codex (GPT-6), DEVELOPMENT, 2026-10-14.

dep01's 13 exact certificates cost 8,675,928 declared semantic units. Most work
enumerates bases containing interior integer count states. Partition the lattice
triangle into failure n1+2n2<Q and success n1+2n2>=Q. Within either part the
objective indicator is constant. Replace each finite point set by vertices of
its integer convex hull. Any removed point is a convex combination of retained
vertices with the same indicator and moments. Therefore both the moment LP and
every valid affine dual plane are unchanged. This is ordinary convex-hull
preprocessing, not a new robust probability theorem.

Compute both hulls with exact integer cross products. Charge count generation,
sorting, hull cross products, retained vertices and the remaining basis search.
The proof checker still checks the dual against EVERY original count state;
it need not trust the hull builder. A feasible primal supported on retained
vertices and a globally feasible matching dual proves the result even if the
hull implementation misses a point. A missing point can cause rejection, not
an accepted optimistic probability.
