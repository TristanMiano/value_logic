# rr01: paid on-demand reuse of positive and negative response regions

Prospective DEVELOPMENT, Codex (GPT-6), October 14, 2026. Same 16 exposed
latent-cost source/tolerance duties and finely spaced cost law as lp02; 128 new
requests per arm, seeds 8143300+100*sourceIndex+quota. The query menu, bundle
tariff, exact robust initial action, source admission and preliminary-spend cap
are unchanged. All selective methods use the same fixed initial threshold order.

Arms: regions; ordinary_regions (identical conventional method); positive_cache;
early_local; threshold; relevant_audit. Every adaptive arm first checks whether
an existing action or retained interval closes before invoking the ordinary
local action proposer. Positive caches retain full action-completion intervals
with exact prior-observation context and source identity, allowing reuse across
different answers. The regions arms additionally retain the two-witness lower
bank and strict negative intervals; a negative hit or positive ambiguity floor
skips an immediate action search and proceeds to the next audit. This does not
claim skipped search could never help prepare a later branch.

Cache entries are created only from actually reached states, durably saved
before use, and capped at 16 entries per exact prior context and 4,096 total.
They are source-bound and include the last query map; strict negative endpoints
are not treated as closed. A fresh exact source-diagram regret check and original
clause checks validate every output. Cache lookup, proof construction/checking,
failed proposals, retention, floor updates and admission are billed in named
units. Every arm purchases its own physical receipts on the shared seeded worlds.
This is DEVELOPMENT; no free replay, independent confirmation, new minimax
principle or total-economic-cost claim is implied.
