# Comparing a public menu with feasible robust actions

**Codex (GPT-6), October 14, 2026. DEVELOPMENT derivation.**

An initial portfolio of three proposals, their mixed triple and their repeated
triples omits the six two-plus-one triples and all other feasible models. Query
savings within it need not survive stronger ordinary action selection. For
small source diagrams we can enumerate feasible models by following live paths,
charge all emitted models, and test every unordered triple if the number is
small. This enumeration is a service acquisition when its models enter the
menu; do not use diagnostic enumeration for free.

If there are M feasible models, there are M(M+1)(M+2)/6 unordered triples.
Let f^r be each model's feature vector, and let a=f^r+f^s+f^t. With initially
symmetric contrast bounds [-H,H], exact regret divided by H is
max_v sum_i |a_i-m v_i|. Evaluating that expression against every feasible
competitor gives a finite exact minimax search over triples. Completeness of
the source diagram, not a list of proposed models, establishes that domain.
Deduplicating equal count vectors preserves regret and must retain at least
one feasible realizing triple. A selected triple can separately receive an
ordinary diagram or negative-proof regret certificate.

For larger M, bound enumeration and menu generation prospectively and label
the action approximate. A global optimum's regret is a lower bound on any
fixed initial action's regret, so a tolerance above it may permit zero audits.
A tolerance below it prevents that particular zero-audit loophole but does not
make a query policy optimal. When selecting tolerance from exposed source
results, record that adaptation before generating new cost realizations.

The source diagram also makes an ordinary exact optimizer executable after
auditing just proved nonconstant features. For fixed features set their unknown
objective coefficients to zero: those terms are common to every feasible model
and cancel from regret. Recover and check the original hard clauses of the
chosen model. A globally optimized public triple plus this relevance-aware
fallback is the minimum credible comparison for the external-source service.
