# rc03: matched paid retained-certificate service

**Prospective DEVELOPMENT; Codex (GPT-6), October 14, 2026.**

Use seven exposed mathematical sources: path4, path8, hyper8, split4, mixed6,
mixed8 and zero4. They span direct and resolution-derived covers, a larger
hypergraph, expensive mixed-polarity extraction, and an initially free control.
These are generated development inputs, not an external generalization set.
For each, the original CNF and three supplied complete models are frozen inputs.
The requested action consists of m=3 independent source copies with common
feature costs. The menu includes the three-model action and three identical
copies of each supplied model. All final actions are original-source checked.

Admit an ordinary greedy integer packing for each action's initial induced
objective; retain every certificate. Let R0 be the smallest initial regret upper
over this menu. For quotas 2 and 6, tolerance is max(0,R0-quota). Preserve cases
with R0=0 as initially complete, rather than replacing them with favorable cases.
The tolerance and menu are fixed before any new costs are generated.

Feature costs are independent uniform {0,2,4}; individual fees are 1,2,3 cycling
by feature index. A full-information bundle costs C=ceil(0.75 sum individual
fees), regardless of prior queries. A fallback may instead buy all remaining
individual costs if that is cheaper. Its pre-fallback query budget is C. Every
physical purchase produces a request/source-bound receipt; every retry makes
new purchases and retains the failed prefix. A simulation tariff is not an
external monetary price.

Execute 128 fresh requests per source/quota, seeds 8142300+100*source_index+quota.
All arms have matched hidden worlds and the same information menu; an arm gets
values only through its own provider calls. These are new development streams.

Arms: prefix compiler; identical ordinary-prefix; adaptive greedy expected
capped certificate gain per fee (with fallback as an option); static threshold
order with budget C and no optimized cutoff; audit-first with retained cuts;
direct audit-first with no cut compiler. All initially check their admitted
action certificates. All retained-cut arms may close from any menu certificate
after each receipt. Direct uses nonnegative-objective lower zero before actual
complete solving. The first four arms have the same budget cap. The two prefix
arms evaluate all action/order/cutoff candidates and charge all preparation.

After full information, every arm first tries its available certificates. Only
if unresolved does it actually invoke the finite complete branch-and-bound
provider, obtain a negative proof below its optimum, independently check it,
and return m copies of the optimal original model. No arm is forced to solve
when its retained certificate already suffices. There is no native oracle.

Charge source admission, actual resolution generation/checking, retained words,
all candidate compilation, receipts, every attempted menu check, final checks,
and actual fallback proof production/checking in declared named-unit categories.
Allocate the historical rc01 model enumeration invoice equally to every arm;
it is reused proposal work, not new acquisition. Setup is included once per arm
at the executed 128-request horizon. Report intermediate cumulative horizons
only from actual executed prefixes, without replacing the declared full result.
Source generation, host/native runtime, storage byte-time and external prices
are unmeasured, not zero. Named units are counters, not elapsed computation time.

Freeze implementation, dependencies, source/action/tolerance values and this
declaration before fresh provider generation. Save every request after each
purchase and after final checking. Reconstruct invoices and source-bound
certificates independently, with exhaustive compatible-box checks on the n<=4
sources and all observed worlds on larger ones. Include mutated receipt/source,
objective and proof controls. The ordinary mirror is expected to tie; this tests
the integrated capability and resource tradeoffs, not novelty over itself or F01.
