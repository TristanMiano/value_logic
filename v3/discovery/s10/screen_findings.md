# Retained-cut screens and the action-menu correction

**DEVELOPMENT; Codex (GPT-6), October 14, 2026.**

rc01 finished 15 source units, all first attempt. It checked 18,384 interval
states, 83,106 exact corners, 76,848 single-coordinate contractions, 381 exact
probability convolutions and 104 altered-input controls. Retained dual structure
was strictly stronger than scalar-only audit transport in 13,545 coordinate
states. The source models were enumerated for diagnostic comparison; none of
these observations is an actual cost purchase or a confirmation result.

All initial sources and frozen executed modules remain in rc01. The bounded
resolution extractor found no positive cut in mixed4 or zero4, which correctly
retains the zero lower bound. On mixed6 and mixed8 it produced 144 and 164
derived clauses; full setup costs were 122,905 and 77,741 named units. The other
13 sources cost 157--1,170. The extractor is partial, and these generated source
families do not establish scalable recognition of arbitrary CNF.

rc02 compared the exact prefix compiler with exhaustive supported-world fees
on all 30 source/quota cases. Every expectation and B+C cap matched; eight
cases chose immediate fallback. Compiler costs were 190--1,506 named units.
The predicted fee savings span 0--85.87%, but these are modeled fixed-certificate
comparisons against a full-information bundle, not paid service measurements.

The screen deliberately fixes the supplied repeated action. That restriction
cannot support a claim about a broader service that may return any repair.
In particular zero4 has an admitted zero-cost feasible model, so a strong
controller can close immediately without auditing. Some high-tolerance cases
also admit an alternative public action. The next service must check the whole
declared public action menu before purchases, and set its tolerance from that
menu prospectively, not suppress these free closures after seeing outcomes.

For each source, retain the mixed repeated action and m identical copies of each
public model. Propose a checked packing for each count vector and compute its
initial bound. If the minimum is zero, record an initially complete control.
Otherwise choose declared quotas relative to the minimum bound. Compile each
candidate's prefix policy, paying for all candidates, and choose the least
expected-fee plan. Additional valid early closures from other retained action
certificates can only improve its physical fee; the chosen fixed certificate's
computed expectation is then an upper bound, not necessarily equality.

This menu expansion was chosen after mathematical screen results and before
any paid request stream. It is an explicit development revision, not a hidden
change to a frozen confirmation experiment. A conventional controller receives
the same menu and all checked certificates.
