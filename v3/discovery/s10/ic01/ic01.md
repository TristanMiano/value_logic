# ic01: continuous one-query contingent-action certificates

Prospective DEVELOPMENT, Codex (GPT-6), October 14, 2026. All eight previously
admitted SATLIB sources, both ds01/cp02 tolerances. Generate every unordered
feasible triple, deduplicate equal feature-count vectors, cap 50,000 triples.
For each proved relevant coordinate compute the closed response interval on
which each action meets the full remaining-box regret tolerance. Costs remain
continuous in [-4,4]; represent interval endpoints exactly in sixths, since
three-copy slopes have absolute value at most three. No rounding into gaps.

Greedily find a covering subfamily of these intervals for each coordinate,
retaining an action per interval. Validate every retained interval at both
endpoints against every source-complete feasible competitor and separately
through a scaled integer source-diagram objective. Convexity then certifies
the whole interval. Report uncovered gaps, including gaps between the five
earlier sampled answers. Price source admission, model and action enumeration,
interval construction/checking and storage before any paid improvement claim.
This screen buys no physical information; a successful cover permits a later
actual one-query service with a distribution-free fee guarantee on the entire
continuous box. Compare with ordinary contingent-action/robust optimization.
