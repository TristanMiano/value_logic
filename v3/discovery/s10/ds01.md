# ds01: paid signed-cost service with exact ordinary compilation

Prospective DEVELOPMENT, Codex (GPT-6), October 14, 2026. Eight already exposed
SATLIB uf20-01 through uf20-08 sources; newly imposed repair-only paired-cost
duty, three feasible copies. Each true and false cost is independently uniform
on {0,2,4}; observe their contrast in {-4,-2,0,2,4}, probabilities 1,2,3,2,1 /9.
The common false-cost baseline cancels from repair regret. This is not an
empirical SATLIB cost law or the earlier positive-only duty.

Use the exact source-bound diagram, checked pruning, and complete feasible
model enumeration (all these sources have at most 29 models). Exact initial
three-copy minimax search chooses the starting action. Tolerances are its
initial [-4,4] regret minus quota 2 or 6, clamped at zero. This source-informed
choice is declared before the new streams, not independent confirmation.
There are 16 streams, 128 requests per arm, seed 8142700+100*sourceIndex+quota.
All arms use identical seeded worlds but purchase their own request-bound
receipts. One coordinate costs 1+(index mod 3); a bundle of the proved relevant
coordinates costs C=ceil(.75*sum relevant fees). Empty relevant sets cost zero.
At fallback choose the cheaper of remaining single queries and that bundle.
Preliminary query spend is capped at C. Output tolerance is checked over the
whole remaining continuous box, not only realized sampled costs.

Arms: marginal (one forward/backward pass gives every query's exact closure
probability for the fixed action); ordinary_marginal (identical conventional
method); response_scan (same policy but separately evaluates all five responses
of each query); threshold (one initial expected-regret-reduction/fee order);
relevant_audit (learn only proved variable features, then exact optimization);
adaptive_action (globally reselect the best three-copy action after every audit,
then use the marginal query rule for that action). The one-step rule maximizes
F*p(close)-fee, requiring strict positivity, where F is current fallback fee.
Its conditional probability premise holds under this independent cost law.

Every arm actually recompiles and checks its source. Store identical immutable
proof bytes once with separate invocation records. Charge all source admission,
enumeration, action planning, query selection, proof checking, returned-model
checks, retention and physical receipt work in declared named units. Save each
purchase before consumption; preserve failed prefixes. Named counts are not
wall-clock or total-economic-cost claims. The relevant_audit arm can omit robust
action enumeration and planning. Library calls, source archive acquisition,
storage price and universal external computation tariffs remain unknown.

Expected useful evidence: exact behavioral equivalence between marginal and
response_scan, reduced repeated evaluation cost if present, and honest fee and
computation comparisons to the cheaper threshold and relevance-aware fallback.
No claim of superiority to all ordinary methods; an identical ordinary method
is explicitly included. Every source remains in aggregate, including zero-cost
cases. Any retry is new work with preserved failed acquisitions and exposure.
