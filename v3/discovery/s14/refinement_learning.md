# Refine evidence within one fixed cohort

Codex (GPT-6), DEVELOPMENT, October 23, 2026 UTC. A synthesis of the
ordinary sample-span, stable-compression and independent-transversal
ingredients in learn_affine_warrants.md and hidden_rank.md. No new
statistical rate or matroid algorithm is claimed.

Fix N iid cases and the syndrome feature map before sampling. At any
stage t, truthful receipts give sets Z_i(t) containing the same latent
syndromes z_i. Let S(t) span their union, and retain equations S(t)-perp.
Let k_bar(t) be any certified upper bound on rank{z_i}, for example
N-|I|+dim(span(union_(i in I) Z_i(t))) for a supplied index set I.

On the single stable-compression event for this latent cohort,

    P_new(z not in S(t)) <= B_N(k_bar(t),delta)

holds simultaneously for every stage and every truthful adaptive
measurement strategy. This includes stopping when both a required rule
space and a prescribed risk bound have been obtained. Neither the number
of refinements nor the choice of their directions requires a new union
penalty: all reconstructed spans contain the SAME latent sample span.
This does not permit choosing N by peeking at fixed-N bounds, changing
the sampling law, or learning an unrestricted feature map for free.

With nested refinements, S(t) can only shrink, so more equations become
available. The optimal hidden-rank upper bound can only decrease. Thus
more informative receipts can improve both the retained equation space
and its reported confidence bound. The true latent rank and its actual
confidence event do not change; initially loose evidence simply hid them.

## Several fallible models, one common feature contract

If several models' equations all lie in one fixed feature space, the
latent full-feature span supplies a common protection event. Every
retained linear rule that vanishes on all latent training vectors is
true on that span. Their conjunction, arbitrary later selection, and
adaptive inferences within a new case are therefore covered together.
The complexity belongs to the COMMON feature/sample span. One cannot
substitute each model's smaller rank separately and then combine their
confidence claims without a joint argument. Different cohorts likewise
need an explicit simultaneous bound or a justified common event.

This is conventional linear-hull learning, expressed as a reusable
contract for provisional models. Fixed nonlinear Boolean features are
allowed mathematically, but acquiring and evaluating them is paid work.
The construction does not solve uncertainty about arbitrary mathematics.

## What is protected, and what it costs

The risk is unconditional per new iid case. If releases occur with
probability a, their conditional error is bounded only by min(1,epsilon/a)
without further selective calibration. Multiple future cases, shifts in
the case distribution and receipt errors require their own accounting.

All N cases were sampled. Every paid measurement, failed purchase,
containment check, rank certificate and rule-generation operation counts.
Small compressed final evidence does not mean small acquisition cost.
For raw coordinate receipts, the common-row-space obstruction in
learn_affine_warrants.md can make the entire construction useless.

The prospective useful duty is a fixed cohort with reusable, naturally
available linear measurements and adaptively chosen additional checks.
The next cheap comparison should ask whether direct validation of one
preselected warrant is cheaper. A generic benchmark or a general-learning
novelty claim is not justified by this derivation.
