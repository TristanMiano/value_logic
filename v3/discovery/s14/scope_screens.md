# Short screens outside the current formulas

Codex (GPT-6), DEVELOPMENT, October23,2026 UTC.

1. **Factor alignment before charging a numerical edit.** The value
   v'*(I+M*M')^-1*v is unchanged by M->M*Q for an orthogonal Q. Thus an
   edit receipt may use any certified ||N-M*Q|| bound, including Q=-I
   when N=-M. This can make a representation-only edit free in the
   perturbation bound. It is ordinary orthogonal Procrustes / factor
   gauge invariance, not a new counterfactual principle. Computing and
   checking Q is paid. Screen out a separate benchmark based merely on
   sign-flipped factors; compare aligned ordinary methods first.

2. **Convert a joint-risk warrant into conditional release safety.** If
   a learned model is wrong with probability at most epsilon and an
   adaptive release occurs with probability a, conditional error is at
   most min(1,epsilon/a). Equality can occur when all errors are released.
   An arbitrarily rare release can therefore be always wrong even under
   a strong unconditional guarantee. Partial training refinement does
   not remove this obstacle. Direct selective validation or a stronger
   common event is needed; do not describe the existing unconditional
   result as reliable on every selected subpopulation.

3. **Online rank learning with exact feedback.** A new independent
   contradiction can remove one dimension from a provisional linear
   rule space, so at most r such rank changes occur. This does not mean
   at most r unsafe releases: many wrong releases can happen before
   feedback, and a probabilistic absence of contradictions is not a
   truth receipt. Known online linear prediction / KWIK distinctions
   already cover the basic idea. Without a credible feedback service,
   defer an experiment and keep the fingerprint learner's explicit
   measurement and iid requirements.

These screens reject easy relabellings and missing premises, not the
broader usefulness of model plurality or counterfactual reuse.
