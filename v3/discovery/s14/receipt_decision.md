# A concrete decision using two partially computed values

Codex (GPT-6), DEVELOPMENT, October 22, 2026. This is an exact certificate
example and an information separation, not a measured application benchmark.

After an old regularized solve, retain truthful intervals

    g(M) in [0.0999,0.1001],
    ||(I+MM^T)^(-1)v||^2 in [0.00999,0.01001], ||v||=1.

A separately checked edit warrant supplies ||N-M||op<=1. The requested
decision is whether the revised value is guaranteed at most 0.24.

The rational partial_receipt_probe.py checker uses alpha=10/9 in the
conservative upper rule from partial_two_scalar.md. Four outward square-root
enclosures and rational arithmetic yield

    0.05873935478... <= g(N) <= 0.22659054698... < 0.24.

The stored JSON contains exact rational endpoints. No new matrix operator
application occurs in the receipt_band certificate function. The whole probe
also evaluates 144 finite matrix examples; the output's zero-operator field
describes the certificate function, not all work in the validation harness.
The recorded harness runtime is 4,114,200 ns, not a measured speedup.

The one-scalar sharp upper envelope from the same value interval is about
0.26207 and cannot settle this threshold. This is not merely failure of a
weak upper-bound formula: the one-scalar source admits old response1/10,
new response32/125=0.256 and edit distance39/40<1. The finite rank-one
construction in finite_extremizers.md realizes that pair. Its old second
moment is5/178, outside the newly retained interval. Thus the second receipt
excludes a genuine adverse possibility that the first receipt cannot exclude.

## What is paid and what remains open

The additional receipt is a certified squared norm of an old solve vector.
An approximate primal/dual gap can bound it as described in second_receipt.md.
Those operator applications, norm calculations and outward errors are charged.
Retaining two intervals takes four scalar endpoints instead of two; storing
the source/version identity and distance-warrant provenance is also necessary.
A supplied edit bound is not evidence that a named matrix revision actually
satisfies it unless the source/revision binding has been checked.

The practical comparison is a retention choice: two scalar intervals versus
one interval, full primal/dual vectors, or a new solve. The latter options
may be cheaper or tighter on a particular workload. The example establishes
a new warranted decision under a richer small receipt, with no measured
complete-cost, audit-fee or CPU saving. An ordinary implementation of the
same formulas has exactly the same outcome.

The possible useful contribution is the sharp information contract, the
explicit partial-arithmetic checker and the choice of evidence to retain.
Robust least-squares and conic ingredients are established. A natural stream
with a meaningful memory/compute budget, and a closer novelty comparison,
are still needed before a complete-service contribution claim.
