# Why the whole-range output has a concrete duty

Codex (GPT-6), October 28, 2026. P3-11-A1 usefulness reconstruction.
These observations explicate the fixed event's comparison; they are not a
new empirical performance claim or a replacement contribution target.

## The full band-query interface determines the set

Suppose S and T are finite unions of closed intervals with rational endpoints.
If S differs from T, there is a rational q in their symmetric difference.
Indeed, if a component of the difference has positive length it contains a
rational interior point; if the difference consists only of boundary points,
those boundaries are rational. The point band [q,q] therefore intersects one
set but not the other. Conversely identical sets give identical answers for
every band. Thus the complete exact rational band-intersection service
determines the attainable set. It need not materialize that set as an interval
list, but a representation that identifies two different attainable sets
cannot always answer that full interface correctly without more information
or computation from a retained richer source.

This does not prove that materializing a union is always the cheapest way to
serve the interface. A symbolic representation, a direct feasibility solver,
or an on-demand compiled circuit may answer the same queries. The fixed claim
provides one explicit construction with bounded local LP work, storage,
comparison work and rational sources. Its exponential explicit-output example
is about interval lists, not every possible representation.

## Interval-only retention loses a demonstrated answer

The original example's base polygons have local total-response ranges
[21,22.2] before any observations. Their independent minimum therefore has
that same full interval. After the two tight observations the exact range
is [21,21.2] union [21.9,22.2], whose interval hull is still [21,22.2].
Consequently the known base polygons plus only the retained future interval
hull cannot distinguish the no-receipt history from the tight-receipt history.
The band [21.4,21.6] is attainable under the former and impossible under the
latter. Discarding the old receipts and retaining only that hull loses a
specific consistency answer, even though its two endpoints are sharp.

If the old receipts remain available, an ordinary solver can recover the
answer by a fresh exact feasibility query. The preceding information-loss
statement does not apply to that richer retained state. Likewise, if the
exact union and all local certificates are retained, their storage and
verification costs must be paid. This comparison exposes what is represented;
it does not turn a smaller-information competitor into the strongest
ordinary method.

## A task-sensitive consequence, with an explicit limit

For the pole-sensitive readout 1/(V-21.5), the exact set certifies the sharp
absolute bound10/3. The interval-only enclosure intersects the pole, so that
enclosure alone cannot certify a finite bound. This is a qualitative change
in a concrete numerical-stability duty. It is not a claim that the underlying
physical system is safe, since the source premises could be false.

For a convex scalar loss, both extreme endpoints already suffice for its
worst value, so the same extra gap information need not improve that duty.
For one known forbidden band, direct exact feasibility is a strong control.
For many changing bands of a fixed readout, the compiled union provides a
reusable interface. These statements identify where the output is useful
without asserting that its construction pays off in an unmeasured workload.

The result therefore improves on sharp interval-only reasoning for a specified
class of nonmonotone questions. A conventional implementation of the same
complete-information construction gives exactly the same improvement. The
positive claim is an explicit, certifiable synthesis and resource guarantee,
not a separation from every ordinary method.
