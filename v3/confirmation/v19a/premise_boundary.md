# P3-11-A1: what a checked result licenses

Codex (GPT-6), October 28, 2026. Same-model scope and usefulness review.
These are consequences and limits of the fixed contract, not newly promoted
extensions or an empirical calibration claim.

## Three different warrants

The complete rational certificate establishes the calculation relative to
the caller's inequalities. The measurement/reporting process must separately
justify each receipt interval. The model choice must separately justify that
one common latent source lies in the supplied product domain and that its
affine responses describe the quantities being queried. A valid dual identity
does not establish either of the latter premises. A canonical input digest
prevents an accidental mismatch with the checked object; it does not supply
provenance, truth or a probability of model adequacy.

One elementary probabilistic implication is available IF the caller has the
needed warrants. Let E0 be the event that the source/model premises hold,
and Ej the event that receipt j contains its corresponding true readout of
that same source. If P(E0 fails)<=beta and P(Ej fails)<=alpha_j, then on the
intersection of these events the exact output R contains the true future V.
The union bound gives

    P(V not in R) <= beta + sum_j alpha_j,

with the trivial cap at one. No probabilistic independence is needed. This
does not create calibrated alpha_j or beta from a mathematical certificate.
Adaptive data selection needs coverage assumptions that remain valid under
that selection; nominal pointwise intervals do not automatically suffice.
Many weak receipt guarantees can make the joint bound vacuous. No such
coverage numbers have been established for the constructed worked example.
For a producer that can refuse to return a certificate, the corresponding
unconditional statement bounds the event 'an answer is accepted AND misses
the true value'. It does not give the same error bound conditional on
acceptance. Selectively displaying accepted cases can change that rate.

## Fixed source versus drift

With one scalar source in[0,1], reports x=0 and x=1 are jointly inconsistent
under the fixed-source model. They can both be accurate measurements of a
system that changed between observations. The empty output then diagnoses
the conjunction of fixed-source premises and reports, not which report is
false or whether the changing system is impossible.

Some bounded drift can be represented within the theorem by making each x_i
a whole finite trajectory, with rational linear within-block transition
constraints and affine observation forms. This is an input interpretation,
not a new filtering theorem or a guarantee for arbitrary dynamical systems.
Cross-block couplings remain outside the product premise. Simply putting all
variables into one block generally makes the old minimum readouts nonaffine,
so it does not remove that restriction for free.

## Receipt withdrawal is not just forgetting an assigned upper witness

Every stored local slice includes the lower inequality of EVERY receipt.
Its subset index T controls only which upper inequalities are imposed. Thus
querying fewer upper-witness obligations in the old tables does not withdraw
the corresponding lower bounds.

For n=1, B=[0,1], one receipt x in[1/2,1] and future f(x)=x, both the old
empty-subset slice and the assigned slice have image[1/2,1]. Withdrawing the
entire receipt should instead give[0,1]. Treating an empty subset index as
full withdrawal loses all values below1/2. The frozen service compiles a fixed
problem; it does not advertise that invalid withdrawal operation. A changed
receipt contract requires appropriately recomputed or separately justified
local evidence and a new input binding.

## Which changed-readout operations can reuse evidence

The old local cells do not depend on the future objective, but their extrema
and objective duals do. For a general new affine readout the old endpoint
certificate is not automatically a certificate of its extrema. The unchanged
Farkas certificate of an empty cell remains relevant because it involves
only constraints. This distinction concerns mathematical reuse; the fixed
input-binding mechanism must still identify the changed problem explicitly.

For a common positive affine transformation f'_i=a*f_i+b with a>0, the
future minimum and its image transform as V'=a*V+b and R'=a*R+b. For a=0,
the output is{b} if the source is nonempty and is empty otherwise. A common
negative coefficient instead turns the old minimum into a maximum, so the
merged old minimum range alone is insufficient. If all local extrema and
witnesses are retained, a negative affine transformation swaps/scales local
extrema and their duals, after which the same combination theorem can be
applied. That is a justified recomputation, not an invariant old answer.

## When preserving gaps changes a decision

For a fixed readout, the full interval union answers all later band queries
and supports the specified source reconstructions. The original noisy
example certifies distance at least3/10 from the pole21.5, hence an absolute
reciprocal bound10/3. A numerical routine whose declared precondition is
distance at least1/4 from that pole can be certified on this source. The
hull alone cannot establish that precondition. No runtime or economic saving
for a real routine has been measured here.

Conversely, a worst-case convex loss on a scalar hull is maximized at one of
its two endpoints, which the compact exact image also contains. For that
duty the gaps add no worst-case-loss information. A one-off band can also be
checked directly without compiling the whole range. The contribution must
therefore be stated for a duty that uses the retained gaps, with the actual
LP, certificate, storage and query costs charged. It is not an automatic
advantage for all decisions or all bounded reasoners.
