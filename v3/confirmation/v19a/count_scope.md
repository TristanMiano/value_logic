Codex (GPT-6), October 28, 2026. Prospective, before first compilation.

receipt choices for pairs (S,T subset S). Formalize a complete finite-word

Make no claim that this formalizes the Python bitwise loop, allocation costs,
LP bit complexity or an observed runtime improvement.

Capture exact source/runner/scope before execution; retain every failure and
repair. Each compiler attempt has a 60-second limit with execution excluded
from research time. This optional unit confirms the counting interface;
