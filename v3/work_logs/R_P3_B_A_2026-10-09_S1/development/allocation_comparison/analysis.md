## Contract and protocol

This is a stronger input contract than the uniform broker's sequential
request interface. The entire current block of public mathematical queries
is available before allocation. The tape is fixed without computing labels:
list `p` in `(17,31,47,61,97)` and `a=1,...,p-1`, then take domain position
`(73*t+19) mod 248`. All three arms use four fixed public binary experts,
16 state bits, 16 action bits and seed 307201. The public query semantics
and all ordinary shortcuts remain the existing service's Euler-residue
question. No unpurchased truth is passed to the learner.

Within a block, weights and expert advice are frozen. The favorite maximizes
weighted binary disagreement divided by a source-fixed public proxy. The
proxy is 128 on the elementary inputs `a=1` or `a=p-1` and 304 otherwise;
these values are selection heuristics, not the charged actual invoice.
Every position receives one ticket and the favorite receives `B` additional
tickets. Thus there are exactly `2B` tickets; the favorite has probability
`(B+1)/(2B)` and every other position has probability `1/(2B)`. One answer is
bought and checked per block, can correct that round's terminal action, and
updates weights only after the last round closes.

The update uses the selected position's actual propensity through
`gamma=(1/pi-1)/(HK)`, with `H=K=2B-1`, followed by positive fixed-mass
normalization. Its public score, favorite, ticket multiplicity, immutable
issued probabilities, receipt identity, and each normalized weight update
were reconstructed from the completed public records. This audit needed
only purchased labels. Across the batch it verified **5,952 issued rows,
868 exact checked purchases and 868 allocation records**. All state,
buffer, arithmetic, bit-consumption and invoice checks passed.

The public transcript, allocation records and actual receipt invoices were
closed into a ZIP and verified before any private evaluator call. A separate
repeated-multiplication evaluator subsequently produced the private labels

Serialization, evidence audits and rational report algebra are external

## Conservative expectation certificate

\[
\mathbb E L_{\mathrm{terminal}}
\le \min\left\{T-m,\;
L_*+HK\ln4+\frac{HmK}{2^s-1}+\frac{T-m}{2^h}\right\},
\qquad H=K=2B-1.
\]

Here `L_*` is the best fixed expert's full-tape loss: 464 at horizon 992 and
1,856 at horizon 3,968. The bound is an unconditional expectation over
selectors and action bits, not a requirement on any single saved seeded
trace. The driver encloses `ln4` from above using 32 positive atanh-series
terms and an explicit geometric tail, entirely with `Fraction` arithmetic.
It retains both representation and action-rounding allowances. The old
uniform-selector Brier certificate is not transferred to this adaptive
