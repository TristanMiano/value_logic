instances. A hash is not mathematically injective on all admitted records.

current applicability checked by exact canonical bytes, while retaining
fingerprints only as audit references? Can the wrapper likewise compare its
full original task binding rather than just catalogue/request fingerprints?

   reject cross-source reports and accept each original report locally.
2. Force audit fingerprint fields to agree while keeping unequal full source,
   loss or task records. These are diagnostic substitutions, **not discovered
   SHA-256 collisions**. Exact-record comparison must still reject them.
3. Genuine returned source, loss and task records must be historical copies;
   subsequent live mutations/revisions cannot rewrite their retained bytes.
4. Further cube refinement on an unchanged source preserves an older valid

5. A changed catalogue or selected action does not inherit the original task
   certificate even when its visible audit fingerprints are overwritten to
   match another output.
6. Alter only numerical bound fields while leaving the record binding intact.
   The current-warrant helper may still return true: the explicit demonstration

7. Verify the saved AST equality for the numerical/VM/refinement functions and
   the mathematical report/compiler fragments. Report the precise changed
