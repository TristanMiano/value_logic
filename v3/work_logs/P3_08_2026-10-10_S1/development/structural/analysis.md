## What the examples establish

### Genuine counterpossible and tied repairs

The unchanged quoted formula is

```math
\theta=(p\wedge\neg p)\vee(r\wedge\neg r).
```

Both implementations calculate zero satisfying ordinary Boolean valuations.
Their hypothetical evaluator uses the accepted paired positive/negative
support rules. Ordinary normality is defeasible for `p,r` and hard for `q`;
the first case fixes `q` false. Equal positive normality weights, followed by
ordinary-baseline preference, give exactly two minimizing support states:

| Exceptional atom | `(t_p,f_p,t_r,f_r,t_q,f_q)` | `take_p = 4t_r` | `take_r = 4t_p` | Fallback |
|---|---|---:|---:|---:|
| `p` | `(1,1,0,1,0,1)` | 0 | 4 | 3 |
| `r` | `(0,1,1,1,0,1)` | 4 | 0 | 3 |

One action must serve both tied states. Its optimal worst-case loss is **3**.
Choosing a different action after seeing each hidden state would produce **0**;
the program reports that number only as a forbidden diagnostic. The quote,
ordinary interpretation and atomic identities remain fixed. This finite
adaptation does not make a contradiction classically true or assign a
probability to its support states. The fixed falsity constant retains positive
support zero and returns **INFEASIBLE**, with no useful-action warrant.

### Unresolved sources stay outside repair minimization

The second case gives two external sources. Their minimal normality ranks are
respectively 1 and 2, while their fixed `q` values are respectively 0 and 1.
The action losses are `act0 = 4t_q`, `act1 = 4(1-t_q)`, fallback 3. Neither
source is discarded merely because the other has a cheaper hypothetical
repair. The legitimate fixed-action value is again **3**. Jointly minimizing
over source identity and repair rank would discard the second source and
incorrectly return **0**. Every minimizing completion within each source is
retained; reference preferences are disabled in this case.

### Occurrence, shared replacement, copy and predictor

The finite original table is `(0,0,1)`, its specified replacement is `(1,0,1)`,
and the history index is 0. The four call outputs are `A,B,C,P`; the loss is
`6 + A - 2B - C - 2P`. A predictor of the old function remains attached to that
function until an explicit new routing instruction changes its target.

| Operation | `(A,B,C,P)` | Commit loss |
|---|---|---:|
| Condition original `A` on output 1 | Empty target | No warranted value |
| Intervene at actor occurrence | `(1,0,0,0)` | 7 |
| Replace actor call only | `(1,0,0,0)` | 7 |
| Replace actor and shared call | `(1,1,0,0)` | 5 |
| Also change the named copy | `(1,1,1,0)` | 4 |
| Also replace the old-function predictor | `(1,1,1,1)` | 2 |

These are supplied finite tables and routing declarations, not inferred causal
structure or an unrestricted nearest-program search.

## Reproduction and scope

From the repository root, choose a fresh directory:

```bash
python v3/experiments/p308_structural.py --out /tmp/p308_structural_replay
```

The runner refuses an existing output directory. It saves the manifest,
complete inputs and code snapshots before executing a case, writes complete
units incrementally, and preserves a failure record if execution stops.
`run_v3/` is tied to Python 3.12.14 and the source hashes in its manifest;
opcode invoices require that interpreter/runtime context. Different code byte
counts or Python instruction sets are different resource runs even if the
mathematical answers coincide.

This arm concretizes C01–C04, finite R01/I01 and the relevant bounded
U01/U02/V01/V03/V04 interfaces. It adds neither paid statistical learning to
counterpossible semantics nor new identification of repair preferences.
The exact contribution is executable, fully scoped integration and preserved
ordinary equality/adverse comparisons. All broader duty and contribution
judgments remain with the principal P3-08 review.
