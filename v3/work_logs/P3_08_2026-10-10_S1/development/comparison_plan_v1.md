Contributor: ChatGPT (GPT-6 Astra Pro), 2026-10-10. Saved before generation
of the main public query cohorts or their private scores. This is a
DEVELOPMENT plan, not P3-09, a final challenge, or a held-out evaluation.

## Questions

1. Does the live hard-state broker preserve the exact base sampling/update
   path and reduce task losses by the observable corrections?
2. Does that reduction pay for hard-state work against the cache-free finite
   learner, and how does either compare with capable ordinary alternatives?
3. How much depends on checked-provider algorithm, repeated queries, visible
   structure, action prices, and an ordinary controller's additional work?
4. Can the paid public-only reporter produce its declared exact statistics
   and confidence intervals without a private answer read?

## Public tapes and seeds

Use the bounded CNF service's public generator at seed **3081013**, count
**64**, before any new truth evaluation. The supplied n/width/density and
component patterns, including each eighth repeated formula, are public.
This is the **cold_mixed** cohort. The generator's older 32-query service
probe at seed 3081001 is separate, already inspected development evidence.

The **repeat_online** tape repeats the first 32 cold_mixed formulas four
times, changing only request IDs (T=128). The semantic keys are unchanged,
so both the ordinary cache and the live hard store can exploit repetitions.

The **cheap_structure** tape contains 64 requests cycling through four
transparent 12-variable formulas: opposing units, all-positive units, empty
conjunction, and an empty clause. These inputs deliberately expose simple
public structure. Ordinary simplification and caching remain available.
No private-answer balancing or exclusion is performed.

Finite learners and stochastic ordinary controllers use seeds **11,29,47**,
block size **4**, action/state precision **16**, and capacity **128** for
the hard store / **64** for the ordinary cache. These seeded runs check
development behavior; they do not validate frequentist coverage. The base
and hard broker runs at the same seed have an exact common bit path. The
ordinary greedy controller uses its cheaper selector-only random tape, so
its realized feedback positions need not match the broker at the same
numeric seed. Do not attribute that whole difference to action readout.

## Executable methods

- Cache-free finite product learner, uniform and positive-ticket selection.
- Live hard-answer value specialization, uniform and positive-ticket
  selection, otherwise retaining the matching base learner exactly.
- Capped proof/evaluation with enumeration and with DPLL (cap 2048).
- Ordinary probability-to-cost controller with greedy marginal actions.
- Charged full enumeration, charged DPLL, and charged DPLL with exact cache.
- Ordinary combined controller: exact cache, cheap capped DPLL probe,
  additional DPLL selected from public/previous paid cost information, and
  fallible online marginal advice; failures remain charged and censored.
- A uniform base learner using enumeration instead of DPLL, to isolate
  provider implementation costs without denying DPLL to the main candidate.

The combined controller is rerun prospectively at resource prices
**0, 1/100000, 1/10000, 1/1000, 1/100** with symmetric error price one.
Other main methods have price-independent paths here; the same retained
record is repriced explicitly. A new price-sensitive policy path is never
inferred from that repricing. Asymmetric action prices may be a separately
declared development extension, not silently inserted into these results.

The ordinary probability-to-cost representation can implement the exact
same randomized finite policy by the elementary binary cost map. A named
executable translation wrapper will expose that equivalence using the same
kernel and invoice. It is an implementation/representation control, not an
independently discovered second algorithm or a second random trial.

After all public policy and report records seal, the evaluator computes
truth independently from the public CNFs. A separately labeled **free
truth oracle diagnostic** receives those answers and has zero charged
deployment units. It is excluded from implementable-method rankings.

## Matching and accounting

The main comparison is the same terminal binary-answer service at the
declared deadline, with actual resource coordinates and complete received
answer records. Earlier issued Brier loss is a separate diagnostic; a
proof/evaluation method is not disadvantaged by treating its pre-computation
half forecast as its final checked answer. No semantic or economic advantage
is inferred merely from a richer optional reporting obligation.

All methods receive the same public query data and installed platform.
Cold source procurement is charged once per fresh episode with a common
declared source registry; its identical amount is reported separately from
local execution. Local setup and ongoing units remain separately visible.
The optional paid live-performance report has its own source and execution
add-on. The ordinary translation control can provide the identical report
at the identical bill. No reporter cost is hidden in offline scoring.

Record by-category invoices, provider attempts/successes, hard/cache hits,
precision/bit consumption and all failure states. Preserve failed versions
and amended results. Execute a copied full transitive project source closure
and hash it before and after use. Python/interpreter/native primitives are
the explicit finite word-tariff environment, not a physical hardware claim.
The separate structural VM tariff is never added to these resource units.

## Interpretation

Retain every row and adverse comparison. Report paired hard/base effects,
the empirical error/resource frontier, and exact pairwise price thresholds
for fixed records. A best method chosen after seeing a particular query's
truth is an oracle, not an executable ordinary controller. A best recorded
whole method at a declared price is a retrospective comparator, not a
new deployable selection guarantee. Positive development gaps do not settle
Q3 or establish a general advantage over ordinary methods.
