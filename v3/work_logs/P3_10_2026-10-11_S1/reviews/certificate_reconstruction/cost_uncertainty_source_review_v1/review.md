## Common additive overhead: exact threshold algebra

Let C and O be two known completed-path totals in the **same** tariff and at the **same** comparison scope. Suppose, as an explicit hypothetical allocation assumption, the missing prefix adds the identical amount u >= 0 to both. Let tau = 19/20. With positive comparator denominator, the completed 5% saving condition becomes

    C + u <= (19/20)(O + u)
    iff 20C - 19O + u <= 0
    iff u <= 19O - 20C.

The consequences are exact:

1. If C > (19/20)O, adding any common nonnegative u cannot create a 5% saving. A measured failure of that numerical threshold is invariant to all common nonnegative overheads.
2. If C = (19/20)O, the threshold holds only at u = 0. Any positive shared overhead removes that exact-boundary qualification.
3. If C < (19/20)O, the qualification is established for the common-overhead model only over 0 <= u <= 19O - 20C. If u is unknown without a usable common-tariff upper bound, a positive 5% end-to-end claim is not established.
4. If an independently justified common-tariff interval [u_min, u_max] exists, a threshold pass for **every** permitted u requires u_max <= 19O - 20C; failure for **every** permitted u follows when u_min > 19O - 20C. Otherwise the threshold is partially identified. The actual structural bound above is not automatically such an interval in the broker or certificate tariff.
5. If O = 0, adding a common u cannot create a strict 5% cost advantage: for u > 0, C + u >= u > (19/20)u, and u = 0 leaves the frozen positive-denominator requirement unmet.

Cost differences and ties are stronger invariants: (C + u) - (O + u) = C - O. A candidate that is no cheaper remains no cheaper; a cheaper path retains the same absolute difference but its percentage saving tends toward zero as shared overhead grows. This distinction explains how unchanged absolute rankings can coexist with a lost practical percentage qualification.

## Primitive prices and normalized objectives

For a genuinely common primitive vector u with nonnegative entries, every completed-path primitive difference is unchanged: (c_i + u_i) - (o_i + u_i) = c_i - o_i. Componentwise order and ties are invariant. At any nonnegative common price vector p, the absolute cost difference p dot (c - o) is invariant, and adding shared priced overhead cannot create a 5% saving that failed at zero overhead. This is conditional repricing of fixed paths; primitive counts of the lost prefix are not known.

An additive priced objective is different from a percentage threshold. If both compared normalized objectives receive the identical increment lambda*u, it cancels from their difference. The broker uses a common price, common stakes and units per scheduled request, followed by fixed hierarchical weights; exact cancellation therefore requires equal increments *after those normalizations and weights*. A once-per-run physical overhead is not automatically identical per request or per configuration, particularly across different horizons or execution/analytic weighting schemes.
