### What the exact certificates establish

Write the supplied expected-loss observations as

```math
z=sLp+b\mathbf 1,
```

where the law $`p`$ is in the full simplex. Under known scale, $`s=1`$; under known offset, $`b=0`$. An unknown scale is one shared **positive** scalar, and an unknown offset is one shared scalar across all supplied rows. Let $`M=L`$ when offset is known, and let the effective rows be the differences $`L_i-L_0`$ when offset is unknown.

A constant target is always known. For a nonconstant target row $`c`$, the checked criterion is

```math
\begin{aligned}
\text{known scale: }&c\in\mathrm{rowspan}\begin{pmatrix}\mathbf 1^\top\\M\end{pmatrix},\\
\text{unknown scale: }&\mathbf 1^\top,c\in\mathrm{rowspan}(M).
\end{aligned}
```

In the second case, the denominator identity recovers the same positive scale $`s`$, so a ratio of linear observations recovers $`c\cdot p`$. A normalization-augmented rank calculation alone is insufficient when scale is unknown. Full-law recovery is checked by recovering every coordinate, with the one-state case automatic. [Inherited information derivation](../../v3/derivations/02_probability_information.md); [independent certificate arithmetic](../../v3/work_logs/P3_10_2026-10-11_S1/reviews/conformance_reconstruction/observer_v4.py).

The observer verifies **138 positive certificate identities**: **37** originally recoverable targets, **37** coordinate decoders in the full-law certificates, and **64** repaired-target certificates. It verifies **43 negative certificates**: **27** target collisions plus **16** full-law obstructions. Every negative witness consists of two strictly positive, normalized laws with allowed positive scales/offsets that give exactly the same observation vector and different target values. It also verifies **48 repair dual pairings**. These are arithmetic proof-component counts within the 36 certificates; they are not additional independent experimental cases.

For a nonconstant requested target family $`C`$, the minimum effective rank deficit is

```math
r=\mathrm{rank}(B\cup T)-\mathrm{rank}(B),
```

with $`B=\{\mathbf 1^\top\}\cup M,\ T=C`$ under known scale and $`B=M,\ T=\{\mathbf 1^\top\}\cup C`$ under unknown scale. If offset is unknown and no old loss row exists, a new reference query adds one to the raw-query count. Constant or empty target families need no repair. Each saved repair includes admissible added rows, exact repaired decoders, and hidden directions whose pairings with the required new rows form the identity. This certifies attainability and the rank lower bound. The minimum is conditional on freely chosen fixed rational loss rows sharing the original law and nuisance. It is not a minimum over a restricted query menu or over decision-only services.

### Three concrete interpretations

**Unknown scale can prevent recovery even when the known-scale augmented rank is full.** In `rational_signed` with unknown scale, the supplied two-row loss matrix has normalization-augmented rank 3, but no scale normalizer in its effective row span. The certificate exhibits

```math
p=(1/3,1/3,1/3),\qquad
q=(46/141,18/47,41/141),
```

with scales **1** and **47/36**, zero offsets, and the same observation vector **(37/90, −1/12)**. The nonconstant target changes from **46/385** to **5207/54285**. Both laws are interior and both scales positive. Adding one all-ones loss row measures the shared scale and attains the one-query repair. The constant target 4 remains known throughout.

**A requested target can be identified while the full law is not.** In `partial_target_offset` with unknown affine calibration, the loss rows are `(0,1,0)`, `(1,2,1)`, and `(1,1,0)`. Their differences reveal

```math
p_1=\frac{z_2-z_0}{z_1-z_0},\qquad z_1-z_0=s>0.
```

The target therefore needs zero repair queries. Nevertheless, `(1/3,1/3,1/3)` with offset 0 and `(1/3,1/6,1/2)` with offset 1/6, both at scale 1, produce the same raw observations `(1/3,4/3,2/3)`. The second coordinate differs. The certificate correctly reports full-law nonidentification alongside successful requested-target recovery.

**An anchor can identify the unknown shared scale and the law together.** For `brier_anchor` under unknown affine calibration, subtracting the constant reference row gives three effective observations $`u_1,u_2,u_3`$. The checked normalizer is

```math
s=(u_1+u_2+u_3)/2>0,
```

and the first coordinate decoder is

```math
p_1=\frac{-u_1/6+u_2/3+u_3/3}{s},
```

with symmetric decoders for the other coordinates. All four calibration modes recover the law with no extra query.
