## 1. The five questions

**Organizing question:** can a value-based reasoner learn to make better
decisions about unresolved mathematics, including which computations to pay
for and which assumptions to revise in a hypothetical?

| Author question | Required phase-three answer |
|---|---|
| How does value logic handle logical uncertainty? | Define a bounded reasoner's information state, unresolved mathematical claims, permitted computations and update rule. Identify inherited capabilities and extensions. |
| How does it handle logical counterfactuals? | Give explicit semantics for at least a finite class of hypothetical program/model changes; explain what remains unresolved for genuine counterpossibles. |
| Does retaining several useful, fallible models help more than common logics? | Produce a separating example, theorem or scoped equivalence/limitation against a strong ordinary combination using the same information and resources. |
| Can usefulness estimates improve over time in ways comparable to Logical Induction? | Map each selected desideratum to an exact reduction, new theorem, finite diagnostic or unestablished claim; evaluate useful decisions and paid reasoning. |
| Can costs/values contain probability information? | Characterize when known loss observations identify probabilities, when they identify only bounds or decisions, and when they confound belief with stakes. |

The commitments remain epistemic nonfinality, pragmatic model use and revision,
and investigating value as a primary semantic object. The numerical carrier,
inference rules, treatment of probability and choice of metatheory remain
revisable. A mathematical proof can be conditional on a named theory without
declaring that theory metaphysically final.

Keep distinct: a proposition's interpretation; current uncertainty about it;
whether a bounded procedure proves it; the consequences of relying on it; and
the cost of obtaining more information. Newtonian/relativistic model coexistence
is a motivating application. It does not by itself select an update rule or
justify a logical counterfactual.

## 3. Comparisons and contribution target

The primary comparison families are Logical Induction, proper scoring rules,
coherent expectations/imprecise probability, bounded probabilistic prediction,
metareasoning, structural-equation counterfactuals, ranked belief revision,
and impossible-world semantics. Exact source locators are in the orientation.

Always include a credible **ordinary combined method**: classical proof or
program checking plus probability/interval estimates, expected-cost decisions,
priced computation and explicit dependency tracking. It gets the same evidence,
actions, stored information and budget. Bare Boolean syntax is an illustrative
control, not the strongest competitor.

The principal exploratory hope is a useful integration of **learning cost
forecasts, choosing computations, and transporting justified comparisons across
declared changes**. A restricted representation or information-retention theorem,
a constructive counterfactual interface, a meaningful limitation, or a useful
synthesis/application may supply a contribution. A change of notation, a
known expectation identity, or an unexplained null result does not supply the
delta. Phase two's supported C4-S result does not pre-approve a phase-three claim.
