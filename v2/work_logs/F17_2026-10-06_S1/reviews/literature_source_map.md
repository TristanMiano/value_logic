## Salient neural interpretation

**Ordinary training gives the network no task-specific reason to organize its
features into one clean eight-neuron block for each expected cost.** The task
loss constrains outputs but leaves many internal organizations compatible with
success. The frozen result therefore tests both the learned input/output task
and accessibility to the registered extraction family. Distributed or mixed
features, another basis, another decomposition, and extraction/control limits
are plausible explanations. DAS is the closest methodological citation for
coordinate versus distributed alignment; superposition is useful context,
not a demonstrated diagnosis of these five networks.

Keep three separate claims: information can be decoded; a specified intervention
changes the output as predicted; one joint causal model describes the ordinary
computation. None implies the next without additional evidence. ND01 supplies
local evidence about extraction sensitivity and control discrimination, while
F15-ND02 remains optional, separately frozen future work.

1. **Bibliography coverage.** `v2/references.bib` is largely the F03 source set;
   later C4/F16/neural citations need explicit report entries or bibliography
   additions. Do not imply that file already contains them.
2. **Version identity.** Retain the inspected arXiv versions when theorem
   locators come from them. The final ICLR patching paper has four authors;
   F14's three-author preprint remains a correctly labeled historical record.
   The 2023 Chebyshev preprint and later differently titled journal article
   must not be silently interchanged.
3. **Classical rank attribution.** Cite Gasanova–Nicklasson directly beside the
   equal-price rank. Lead the local theorem discussion with revision, repair,
   and compatible recovery, rather than suggesting that maximal-chain rank
   was first discovered here.
4. **Coherence terminology.** A nonempty finite set of scenario evaluations
   yields a lower envelope and can be viewed through its Dirac-law convex hull;
   this is a useful finite specialization of established lower-expectation
   semantics. An arbitrary source set is not thereby a calibrated confidence
   region, and an inconsistent empty source is not a vacuous usable guarantee.
5. **Unsupported literature negatives.** The 2022 Choquet-identification
   theorem remains unread. Neither failed access nor the accessible precursor
   proves absence of the local result. The current claim explicitly stops at
   bounded comparison, preserving the named evidence recurrence if displaced.
6. **Semantic and runtime costs.** General preservation or rank minimality does
   not prove lower bounds for every encoding or program. No literature
   benchmark speed or certificate overhead transfers to this implementation.
7. **Evidence categories.** Cite project proofs for local theorems, frozen
   outputs for empirical counts, and literature for antecedents. A source's
   introduction cannot certify our result or an implementation it did not run.
