## 1. Sergei Ovchinnikov — Max-Min Representation of Piecewise Linear Functions

Primary source: https://arxiv.org/abs/math/0009026 ; full text:
https://arxiv.org/html/math/0009026 . The original preprint submission is
September 3, 2000; the HTML rendering date is not its publication date.

Checked the affine-component setup and Theorem 4.1 on max-min representation
on a convex domain. The imported use is narrow: a scalar continuous function
with finitely many affine pieces on the declared convex domain has a finite
max-min expression in those pieces. The F02 supplement separately establishes
that its candidate's monotonicity and common-shift law make active affine
slopes stochastic, and reconstructs the representation argument in its own
notation. The theorem does not preserve physical action identities, resource
costs, a fixed primitive library or a small expression size.

## 2. Marianne Akian, Stéphane Gaubert, Antoine Hochart — Minimax representation of nonexpansive functions and application to zero-sum recursive games

Primary source: https://arxiv.org/abs/1605.04518 ; full text:
https://arxiv.org/html/1605.04518 . The inspected version is v2, May 24, 2017.

Checked the introductory operator setting and definitions connecting monotone,
additively homogeneous maps with game/nonexpansive representations. This is a
comparison lead for candidate T, not an unqualified import of the paper's full
representation results. Finite versus infinite action choices, positive versus
additive homogeneity, and which payoff/transition primitives are available must
be matched before using a stronger theorem. F03 should verify those exact
hypotheses against the final candidate shortlist.

## Packaging documentation (O, not mathematical L)

The Windows/WSL package instructions were checked against the official Git
manuals for `git apply` and `git restore`, Python's `venv` documentation, and
Microsoft's WSL filesystem documentation:

- https://git-scm.com/docs/git-apply
- https://git-scm.com/docs/git-restore
- https://docs.python.org/3/library/venv.html
- https://learn.microsoft.com/en-us/windows/wsl/filesystems

The proposed helper applies to the index only after checking a clean working
state, then materializes only its changed paths from that index. This preserves
canonical patch bytes while allowing Git's local checkout conversions. It does
not use automatic whitespace repairs, reset user work, commit or push. Using
a virtual environment's Python executable directly avoids an activation-policy
change. Local package tests exercise the helper on Linux, including a CRLF
checkout simulation; they are not a claim of a native Windows run.
