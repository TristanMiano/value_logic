# F05 S1 source orientation and import boundary

Access: September 26, 2026. This is a small orientation check, not a new F03
survey or an independent verification of entire papers. Primary HTML/text was
read before the protected derivation block; no separately measured L credit is
claimed. No new PDF figures were analyzed or redistributed.

1. **Bacci, Mardare, Panangaden and Plotkin, Rational Lawvere Logic (CSL 2026).**
   Primary text:
   https://drops.dagstuhl.de/storage/00lipics/lipics-vol363-csl2026/html/LIPIcs.CSL.2026.3/LIPIcs.CSL.2026.3.html
   Relevant interface: arithmetic valuations, additive judgments, the truncated
   residual, and the published language's richer operations. The provisional
   core uses a cost interpretation and finite signed difference-pair adapter;
   this is not an import of RLL's full proof system or completeness theorem.
   Source-aware empirical premises, observations and policies need their own
   semantics. The native CPWA limitation is not a limitation of full RLL.

2. **MOSEK Modeling Cookbook, linear optimization / duality.**
   Primary documentation: https://docs.mosek.com/modeling-cookbook/linear.html
   Relevant interface: finite linear inequalities and certificates over explicit
   nonempty sources. F05 supplies feasible rational examples and point checks;
   it does not implement an optimizer or import a conic attainment theorem.
   The exact source/certificate reconstruction already recorded in Gate A and
   F04 remains the comparison baseline.

3. **Perdomo et al., Performative Prediction (ICML 2020).**
   Primary proceedings: https://proceedings.mlr.press/v119/perdomo20a.html
   Checked scope: abstract/problem interface in which prediction can affect the
   distribution being evaluated. It is an antecedent for report-dependent
   behavior, not a theorem of unrestricted logical reflection. Our two-branch
   model, version-changing counterexample and finite visible-policy table are
   separately specified. No general performative-learning guarantee is imported.

The [Gate A review](../checkpoints/A_1.md), [F03 source register](../literature/F03_sources.json),
[DIR01](../decisions/DIR01_loss_grounded_reflective_direction.md), and earlier F04
source notes retain their original scope. Ordinary finite linear algebra,
piecewise-affine arithmetic, pointwise comparisons and conditional expectation
are established tools; no priority claim is made for independently reconstructing
them. The project-specific question is what a useful loss-based inference
interface preserves through composition, evidence changes and bounded self-use.

The externally supplied validity of a loss model or source set is not discharged
by this literature note or by numerical consistency. Empirical modes still need
their stated deployment and coverage assumptions.
