## 2. Frozen scientific fixture and revision contract

Integrate f(t)=a+d*t+b*t^2+c*t^4 over [0,1]. Write beta=b/6+c/3 and
gamma=-c/30. Composite trapezoid T_n has exact signed error
beta/n^2+gamma/n^4. R=(4*T_2-T_1)/3 has error -gamma/4.

The four fixed actions are T_1,T_2,R,F=T_4, with 2,3,3,5 unique evaluations.
Loss is absolute error plus rho times that count, with rho=1/32. Rho is a
stated task preference in integral-loss units; reasoning runtime is separate.
The three queries assert L_a-L_F<=0 for a=T_1,T_2,R throughout the source.
Choose the first certified action in that order, otherwise F. This guarantees
a comparison to F, not minimax-optimal action selection.

Permanent evidence is -1<=beta,gamma<=1. Four optional evidence bundles are
beta+gamma<=r_plus, -(beta+gamma)<=r_minus, |beta|<=b_cap and
|gamma|<=g_cap. Withdrawal of a band removes both of its inequalities.
The finite development contract has r_plus,r_minus in {0,1/16,1/4,1,2}
or absent and each cap in {0,1/64,1/4,1} or absent: 900 configurations.
Four zero/absent switches give the first 16-state implementation slice.
Every source contains the origin; permanent bounds keep it bounded.

## 5. Falsifiers and measurements

A claimed useful difference fails if it disappears under equal information,
preprocessing, structured alternatives, receipt guarantees and total cost;
if it depends only on a coarse development grid, arbitrary policy order or weak
fallback; or if the closest work already supplies the same substantive result.
A semantic discrepancy first returns to the affected producer/reference premise;
reopen A/B only if a reviewed core dependency is implicated. Generic-mechanism
novelty and uniform full-vector affine savings in the seed are already displaced.
A negative example alone does not establish a new project contribution.

Measure accepted/unavailable/refuted outcomes separately, false certifications,
missed reference-positive answers, selected actions, construction and checking
costs, source/update/search/replay work, stored bytes and DAG nodes. Retain
unfavorable sequences. Distinguish cold start, warm cache and amortization:

    C_build + sum_j(C_maintenance,j + C_fallback,j) < sum_j C_ordinary,j.

A lower replay time alone is insufficient. In a stationary simplification,
ordinary cost c, maintenance a and miss fraction m yield a break-even horizon
only if (1-m)*c-a>0; then it is C_build/((1-m)*c-a). Actual sequence totals
prevail. Count premise generation and numerical enclosures if a later case
requires them. Host interpreter crashes and timeouts are not logical refutations,
and isolated microtimings are weak performance evidence.
